\section{实验概述}

本实验基于多数字 MNIST（multi-digit MNIST）数据集完成一个语义分割任务：输入为大小为 $64\times 64$ 的 RGB 图像，输出为同分辨率的逐像素分类结果。类别数为 11 类，其中 0 为背景，1--10 分别对应数字 0--9 的语义区域。模型输出为 logits（未经过 softmax 的分数图），训练阶段使用二维交叉熵损失进行监督学习，验证阶段使用 mean IoU 作为主要评价指标。

数据集在加载时已经完成了必要的预处理：图像读入后转为 $B\times 3\times H\times W$，并按固定的 mean/std 进行归一化；标注 mask 为 $B\times H\times W$，标签取值范围为 $[0,10]$。

\section{代码整体框架}

本次作业的代码结构采用“脚本入口 + lib 模块化实现”的形式。训练与验证脚本位于 \texttt{seg-net/image\_segmentation/}，核心功能（损失、评估、推理、数据集与模型定义）集中在 \texttt{seg-net/lib/} 目录下。整体流程是：脚本读取参数并构建模型与数据集，调用 \texttt{lib/core/function.py} 中的 \texttt{train} 和 \texttt{validate} 完成训练与评估。

为了便于从不同工作目录运行脚本，训练脚本开头会将项目根目录插入到 \texttt{sys.path}，从而保证 \texttt{import lib...} 可以成功解析：

\begin{lstlisting}[language=Python]
import os
import sys

_ROOT = os.path.abspath(os.path.join(os.path.dirname(__file__), '..'))
if _ROOT not in sys.path:
   sys.path.insert(0, _ROOT)
\end{lstlisting}

\section{SegNetLite 模型实现与作用}

本实验需要补全的核心文件为 \texttt{seg-net/lib/models/seg\_net\_lite.py}。该文件定义了一个简化版 SegNet（记为 SegNetLite），整体为编码器--解码器结构：编码器使用卷积提取特征并逐层下采样；解码器使用最大反池化（MaxUnpool）结合池化时保存的 indices 将特征恢复到原分辨率，再用卷积细化特征，最终通过 $1\times 1$ 卷积输出 11 类的逐像素 logits。

\subsection{下采样路径（Encoder）}

下采样路径由若干个 block 组成，每个 block 的基本形式为 \texttt{Conv2d -> BatchNorm2d -> ReLU -> MaxPool2d}。其中关键点是 MaxPool2d 设置 \texttt{return\_indices=True}，保存每次池化的最大值位置，这些 indices 将在对应的反池化层中用于“可逆”地恢复空间结构。

在实现中，编码器的通道数与分辨率变化满足作业要求（忽略 batch 维）：
\[3\times 64\times 64 \rightarrow 32\times 32\times 32 \rightarrow 64\times 16\times 16 \rightarrow 128\times 8\times 8 \rightarrow 256\times 4\times 4\]
对应的模块构造代码如下（使用循环生成每层参数，并收集到 \texttt{ModuleList} 便于参数注册与迭代）：

\begin{lstlisting}[language=Python]
for i in range(self.num_down_layers):
   layers_conv_down.append(
      nn.Conv2d(input_size, down_filter_sizes[i],
              kernel_size=kernel_sizes[i], padding=conv_paddings[i],
              bias=False)
   )
   layers_bn_down.append(nn.BatchNorm2d(down_filter_sizes[i]))
   layers_pooling.append(
      nn.MaxPool2d(kernel_size=pooling_kernel_sizes[i],
                stride=pooling_strides[i],
                return_indices=True)
   )
   input_size = down_filter_sizes[i]
\end{lstlisting}

\subsection{上采样路径（Decoder）}

上采样路径与编码器对称，每个 block 的基本形式为 \texttt{MaxUnpool2d -> Conv2d -> BatchNorm2d -> ReLU}。其中 MaxUnpool2d 需要使用编码器保存的 indices，同时还需要提供池化前特征图的 \texttt{output\_size}，这样反池化才能严格恢复到对应层的空间尺寸。通道数与分辨率变化满足作业要求（忽略 batch 维）：
\[256\times 4\times 4 \rightarrow 128\times 8\times 8 \rightarrow 64\times 16\times 16 \rightarrow 32\times 32\times 32 \rightarrow 32\times 64\times 64\]
对应的模块构造代码如下，其中反池化层的 kernel/stride 与池化层一一对应（按相反顺序使用）：

\begin{lstlisting}[language=Python]
for i in range(self.num_up_layers):
   layers_unpooling.append(
      nn.MaxUnpool2d(kernel_size=pooling_kernel_sizes[-(i + 1)],
                  stride=pooling_strides[-(i + 1)])
   )
   layers_conv_up.append(
      nn.Conv2d(input_size, up_filter_sizes[i],
              kernel_size=kernel_sizes[-(i + 1)],
              padding=conv_paddings[-(i + 1)],
              bias=False)
   )
   layers_bn_up.append(nn.BatchNorm2d(up_filter_sizes[i]))
   input_size = up_filter_sizes[i]
\end{lstlisting}

\subsection{输出层与 forward 过程}

解码器输出的特征通道为 32，为得到 11 类像素分类的 logits，需要一个 $1\times 1$ 卷积将通道映射到类别维度：

\begin{lstlisting}[language=Python]
self.conv_final = nn.Conv2d(input_size, 11, kernel_size=1, padding=0, bias=True)
\end{lstlisting}

forward 的关键在于两类信息的保存与复用：其一是每次池化得到的 indices；其二是池化前特征图的尺寸（用于 unpool 的 output\_size）。编码阶段对每层进行卷积与池化，并将两类信息压入列表；解码阶段按照相反的层次顺序取回 indices/size 做反池化，再进行卷积细化，最后输出 logits。

\begin{lstlisting}[language=Python]
pooling_indices = []
pooling_sizes = []

for i in range(self.num_down_layers):
   x = self.layers_conv_down[i](x)
   x = self.layers_bn_down[i](x)
   x = self.relu(x)
   pooling_sizes.append(x.size())
   x, indices = self.layers_pooling[i](x)
   pooling_indices.append(indices)

for i in range(self.num_up_layers):
   j = self.num_up_layers - 1 - i
   x = self.layers_unpooling[i](x, pooling_indices[j], output_size=pooling_sizes[j])
   x = self.layers_conv_up[i](x)
   x = self.layers_bn_up[i](x)
   x = self.relu(x)

x = self.conv_final(x)
return x
\end{lstlisting}

通过上述实现，模型输入为 \texttt{(B, 3, 64, 64)}，输出为 \texttt{(B, 11, 64, 64)}，可以直接与损失函数及评估模块对接。

\section{训练过程关键代码与解释}

训练入口为 \texttt{seg-net/image\_segmentation/train\_mnist.py}。脚本首先构建模型 \texttt{models.seg\_net\_lite.get\_seg\_net()}，损失函数使用 \texttt{CrossEntropy2D(ignore\_index=255)}，优化器使用 Adam。数据集通过 \texttt{dataset.mnist(is\_train=True/False)} 创建训练集与验证集，并用 \texttt{DataLoader} 迭代取样。需要注意的是，MNIST 数据加载器每个 \texttt{.mat} 文件可能包含多张图像，因此在 \texttt{lib/core/function.py} 中会把形状为 \texttt{1 x B x 3 x H x W} 的 batch reshape 为 \texttt{(B, 3, H, W)} 以适配模型前向与损失计算。

训练轮数在脚本中固定为 20 个 epoch，每个 epoch 调用一次 \texttt{train(...)} 完成参数更新，并按设定间隔调用 \texttt{validate(...)} 在验证集上计算 mean IoU。对应的关键逻辑如下：

\begin{lstlisting}[language=Python]
best_perf = 0.0
train_epochs = 20
for epoch in range(train_epochs):
   train(train_loader, model, criterion, optimizer, epoch,
        args.out_dir, writer_dict, args)

   if (epoch + 1) % args.eval_interval == 0:
      perf_indicator = validate(val_loader, val_dataset, model,
                          criterion, args.out_dir, writer_dict, args)
\end{lstlisting}

每个 epoch 结束后脚本会保存 checkpoint，其中包含 epoch、模型参数、优化器状态以及验证指标；如果当前指标优于历史最佳，则同时保存为 \texttt{model\_best.pth.tar}，便于后续单独验证与可视化。

\begin{lstlisting}[language=Python]
save_checkpoint({
   'epoch': epoch + 1,
   'state_dict': model.state_dict(),
   'perf': perf_indicator,
   'last_epoch': epoch,
   'optimizer': optimizer.state_dict(),
}, best_model, args.out_dir)
\end{lstlisting}

\section{验证过程关键代码与解释}

验证入口为 \texttt{seg-net/image\_segmentation/validate\_mnist.py}。脚本会从输出目录加载训练得到的最优模型参数 \texttt{model\_best.pth.tar}，并调用同一个 \texttt{validate(...)} 函数完成评估。验证脚本的关键逻辑如下：

\begin{lstlisting}[language=Python]
model_state_file = os.path.join(args.out_dir, 'model_best.pth.tar')
model.load_state_dict(torch.load(model_state_file))

perf_indicator = validate(val_loader, val_dataset, model,
                    criterion, args.out_dir, writer_dict, args)
\end{lstlisting}

在 \texttt{lib/core/function.py} 的 \texttt{validate} 中，模型输出 logits 会根据需要插值到与标注 mask 相同的分辨率，然后通过 \texttt{argmax} 得到每个像素的预测类别，并在整个验证集上统计混淆矩阵，计算 11 类的 mean IoU 作为最终性能指标。
